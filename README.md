# Recommendation-Systems
This project develops and compares Content-Based Filtering, User-Based Collaborative Filtering, and SVD-based Collaborative Filtering using a synthetic product and user-rating dataset.

The project includes data exploration, recommendation generation, model evaluation using RMSE, and comparison of recommendation approaches.

Technologies: Python, Pandas, Scikit-learn, TF-IDF, Cosine Similarity, SVD, and Matplotlib.

📁 Project materials: Dataset, Jupyter/Colab notebook, visualizations, and final report are included in this repository.
